# JetBrains Mono Nerd Font

This directory contains the JetBrains Mono Nerd Font files used by the Nu Choate League website.

## Font Files

- **Regular (400)**: JetBrainsMonoNerdFont-Regular.ttf
- **Regular Italic (400)**: JetBrainsMonoNerdFont-Italic.ttf
- **Medium (500)**: JetBrainsMonoNerdFont-Medium.ttf
- **Medium Italic (500)**: JetBrainsMonoNerdFont-MediumItalic.ttf
- **SemiBold (600)**: JetBrainsMonoNerdFont-SemiBold.ttf
- **SemiBold Italic (600)**: JetBrainsMonoNerdFont-SemiBoldItalic.ttf
- **Bold (700)**: JetBrainsMonoNerdFont-Bold.ttf
- **Bold Italic (700)**: JetBrainsMonoNerdFont-BoldItalic.ttf

## Source

These font files are from the JetBrains Mono Nerd Font package, which includes programming ligatures and Nerd Font icons.

- Homepage: https://www.jetbrains.com/lp/mono/
- Nerd Fonts: https://www.nerdfonts.com/
